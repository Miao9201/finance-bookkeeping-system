# 财务代账系统 v1.0.4

品牌图形由云形打勾换为账本打勾，继续使用原有蓝色 `#2468ed`、白色、圆润线条与 32×32 SVG / 128×128 EXE 图标尺寸。EXE 图标保留原蓝色圆形底。

顶栏、EXE、启动窗口、打印窗口及桌面快捷方式同步采用新图标；快捷方式优先使用随包附带的同名 ICO，避免沿用旧路径的图标缓存，缺少 ICO 时仍可使用 EXE 内嵌图标。

保留 v1.0.3 的名称列对齐、固定顶栏/左侧导航及右侧内容独立滚动。布局测试和真实 EXE 测试验证文本坐标、鼠标滚轮、菜单切换、小窗口、移动宽度、弹窗、下载、打印、单实例和重启。

业务代码、数据库结构、会计规则、运行依赖、数据位置及备份格式均未改变。截图和自动测试使用虚构数据。
