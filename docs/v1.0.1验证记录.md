本次变更仅统一名称和发布文件，所有客户、合同、任务、票据附件、应收收款、会计、账簿、报表与备份恢复业务保持不变。

继续使用既有 AppData 数据位置、SQLite 文件名、备份格式和单实例标识，避免重新建账或同时打开同一数据库。环境变量和部分内部标识保留历史拼写作为兼容约定。

- 30 项后端测试、数据库迁移和真实进程重启验证通过。
- 浏览器主流程和额外业务回归通过，新增页面标题和品牌文字检查。
- 桌面版本使用原来的 WebView2 宿主及 Node.js 运行时，仅更新品牌文字、程序集名称/版本、导出文件名和打包名称。
- 工作台截图重新从临时虚构数据库生成，未使用客户数据；检查新名称在桌面和移动宽度下正常显示。
- 没有新增数据库结构、会计规则、网络接口、业务依赖或外部平台连接。
- 真实 EXE 的下载、打印、原生另存为、单实例、关闭/重启和异常退出清理测试通过。
- 使用 v1.0.0 代码创建的虚构数据库直接打开后全表及附件指纹不变；原版压缩备份可恢复，附件字节一致。
