# 云代账本地版使用说明

解压 Windows x64 便携包，双击同目录的 `云代账.exe`。可右键运行 `创建桌面快捷方式.ps1` 建立桌面入口；请保留 EXE 所在文件夹。

1. 首次启动可以载入虚构示例，也可以从空白数据开始。
2. 在“客户管理”录入企业、联系人和服务状态，为客户建立合同。
3. 在“代账任务”按客户、会计月份建任务，逐步更新资料、票据、记账、复核和申报准备状态。
4. 在票据模块录入票据并添加附件；会计模块建账、维护科目和期初，录入借贷平衡的凭证，再复核和完成。
5. 合同应收可以分期录入到期日，并登记多笔收款。首页根据实际业务记录汇总任务、合同和欠费。
6. 在账簿和报表查看汇总；CSV 用于导出表格。需要完整迁移时，在“数据维护”下载备份，附件包含在内。

所有税务操作只记录本地准备与处理状态，需要另行在正式渠道申报。本版无进销存和项目核算，不连接真实税务、发票或支付平台。

默认数据库位于 `%LOCALAPPDATA%\YundaizhangDesktop\data\yundaizhang.sqlite`；通过 `--data-dir` 可隔离另一套数据。更新程序保留该目录，替换 EXE 前先关闭窗口并导出备份。请勿将数据库、日志、备份或客户附件上传到公开仓库。

恢复前请核对备份内容；恢复会替换当前业务数据，系统会先保留当前库的备份。CSV 不含全部业务关系和附件，不能代替完整备份。数据库未加密，请妥善管理 Windows 账户与磁盘权限。

需要 Windows 10/11 x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime；不要求用户安装 Node.js。缺少运行组件时请从 Microsoft 官方网站安装。EXE 未作商业代码签名，可核对下载页 SHA-256。

程序关闭后会停止它自己的后台服务，数据继续保留。网页源码运行方式、构建步骤和更多说明见仓库 README。
