# 开发与验证

Node.js 24+、npm 锁定依赖；Windows 桌面打包还需要 Python 3.10+、Windows x64 和系统 .NET Framework C# 编译器。所有数据库测试使用独立临时目录。

| 命令 | 验证内容 |
| --- | --- |
| `npm test` | 客户/合同/任务/票据与附件、应收收款、统计、CSV 和备份恢复；会计科目、期初、凭证平衡与状态、账簿、基础财务报表和结账；金额边界 |
| `npm run test:migration` | SQLite 原生迁移的全表与附件字节一致性、保留原库、拒绝覆盖目标 |
| `npm run test:restart` | 进程关闭再启动后记录仍可读取 |
| `npm run test:ui` | 真实浏览器业务录入与列表交互 |
| `npm run test:ui:extra` | 边界流程与附加界面验证 |
| `npm run test:layout` | 科目名称与表头对齐、内容独立滚动、固定导航、菜单滚动重置、短窗口/移动宽度及弹窗；同一检查也在真实 EXE 中执行 |
| `npm run test:desktop` | 实际 EXE：新增业务、附件、CSV/备份字节、凭证打印预览、单实例、关闭/重启持久化和父进程异常退出清理 |
| `npm run test:native` | Windows 原生另存为对话框选择路径并校验 CSV；WebView2 新窗口保留打印文档内容 |

浏览器测试默认读取标准 Edge 安装位置；其他环境可设置 `BROWSER_PATH`。原生桌面测试需处于可交互 Windows 会话，使用固定调试端口 32991/32992，请串行执行。测试使用 `--data-dir` 创建临时库，并在结束时只清理经路径校验的该测试目录；不会读取默认业务库。

`YUNDAIZHANG_EXE_PATH` 可指定下载后待验的 EXE。调试端口和 `--test-mode` 仅用于本地测试，普通双击不会开启。

桌面构建脚本会校验官方 WebView2 SDK 压缩包摘要。`build-payload.py` 仅从 `server/`、`dist/`、生产依赖和指定运行时/许可文件构建内嵌包；不读取用户数据库。第三方二进制未纳入 Git，版本和获取路径由脚本明确指定。

修改后先运行与变更相关的测试。涉及桌面下载、打印、关闭/重启的改动需要实际 EXE 集成测试，不能仅凭网页测试通过断言原生行为正常。
