# v1.0.0 发布验证

在 Windows 本机从独立干净源码副本安装锁定依赖并构建。验证使用虚构数据和临时目录，不包含真实客户数据库。

- `npm ci`：完成。
- `npm test`：30/30 通过。
- `npm run test:migration`：1/1 通过，全表及附件字节一致，原库保留、目标覆盖被拒绝。
- `npm run test:restart`：真实后台进程关闭后重新启动，客户、合同、应收、收款、票据及附件保留。
- `npm run test:ui`、`npm run test:ui:extra`：通过，覆盖业务录入、会计、报表、备份恢复、账套隔离、到期筛选和任务统计。
- `npm run build:desktop`：通过，自动获取官方构建依赖并生成 EXE。
- `npm run test:desktop`：实际 EXE 窗口、单实例、客户/票据/上传、附件/CSV/备份下载、凭证打印预览、正常关闭、重启持久化、父进程异常退出后的服务清理通过。
- `npm run test:native`：原生 Windows 另存为选择路径并校验 CSV 内容；WebView2 打印新窗口文档内容保留，通过。
- 业务源码逐文件与整理前版本一致。Git 白名单不含运行库、业务数据库、日志、备份、个人路径或认证文件。
- EXE 内嵌包检查：不含业务数据库或日志，保留 Node.js、WebView2、Vue 及生产依赖原始许可文件。

以上证明所列本机流程；不代表真实税务平台联调、全部行业会计规则审计或所有 Windows 配置均已测试。EXE 未做商业代码签名。
